## 网络层

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| 出口公网 IP | 任何直连连接的对端 | 全部应用共享同一住宅 IP 出口；无应用裸连 | `curl ipinfo.io` 走各应用进程实测 |
| 出口 IP 性质 | ASN/类型识别（DC/数据中心 vs 住宅） | 住宅 ASN，欺诈分低，AI 检测与代理检测尽量"检测失败" | iplark / scamalytics / ippure |
| 直连旁路 | 规则外的流量、IP 直连、UDP 裸奔 | 兜底 MATCH 全覆盖；TUN 接管全局；无直连例外 | 规则表审查 + 出口一致性探测 |
| IPv6 出口 | AAAA 解析 + v6 连接 | 关闭 v6 出站（客户端 `ipv6: false` + 系统层评估） | 检测站"IPv6 获取失败" |
| WebRTC 本地/公网 IP | 浏览器 STUN | 非代理 UDP 全禁，STUN 只暴露出口 | ip.net.coffee/webrtc |

## DNS 层

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| 查询转发路径 | UDP/53 被本地网络透明拦截上送 | 境外查询经本地转发器 → DoH → 隧道出口全程境外 | DNS 泄漏检测站中国条目清零 |
| ECS 子网 | 解析器在查询中携带客户子网 | 境外查询由境外 DoH 发出，ECS=出口地 | 检测站 ECS 显示 |
| 应用硬编码 DoH | 应用自带 DoH 客户端绕过系统 DNS | 国内外 DoH 端点域名整体压进隧道（引流不拦截） | 规则表审查 |
| 引导解析（自举） | 节点域名解析死循环风险 | 引导用 IP 字面量 + 国内 DNS DIRECT 规则 + no-resolve | 冷启动实测 |
| 国内域名解析 | 国内服务可用性 | geosite:cn 走国内 DNS 直连解析（可用性折衷，台账记录） | 国内站点访问实测 |

## 系统层

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| 时区 | 系统时区 API，无门槛 | 掩护身份时区（与用户作息匹配即可，如 UTC+9 对国内用户） | `tzutil /g` / 浏览器检测 |
| 系统区域/语言 | GetUserDefaultLocaleName 等 | 区域=掩护国；显示语言可与区域不同（见浏览器层解耦） | 检测站语言信号 |
| UI 语言 vs 指纹语言 | 两者不一致即暴露"刻意伪装" | 界面显示母语，指纹报目标语言，稳定且不矛盾 | ippure 语言信号项 |
| MachineGuid | `HKLM\SOFTWARE\Microsoft\Cryptography` | 轮换为新随机 GUID（脚本备份后执行） | `scripts/rotate-machine-guid.ps1` 回读 |
| 计算机名/用户名 | NetBIOS/环境变量 | 中性化（如 `DESKTOP-<random>`）；改动影响共享/证书需评估 | 台账记录决策 |
| MAC 地址 | 网卡物理地址 | 通常不跨境泄露（不经过出口），评估后一般保留 | — |
| SMBIOS/序列号 | 需要本地权限读取 | 收紧日常权限：日常终端不提权，不可信程序不在管理员环境运行 | 权限实践检查 |
| 输入习惯 | 输入法词库/云同步 | 输入法关闭云同步或限制其进程网络白名单 | 进程网络审计 |

## 软件面

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| 已安装软件列表 | 注册表 Uninstall 键、标准 WMI 查询，普通权限可读 | 高危采集面默认拒外发（进程级）；无法阻止的本地读取按"采集面缺失"设计 | 采集测试 |
| 进程列表 | 系统 API 无门槛 | 同上下两个方面：外发阻断 + 本地读取无法阻止时让读到的内容不指向真实身份 | 采集测试 |
| 开机自启 | 启动文件夹/Run 键/计划任务 | 全量盘点，逐项标注保留理由；无头无脸的一律清 | `references/ops-verification.md` 盘点法 |
| 国产自保护软件 | 本地采集 + 自我保护 | "允许采集、采集面缺失"：不卸载（保持应用可用），但其采集结果不指向真实位置（网络层全压隧道后其自然只采到掩护面） | 网络审计其进程 |
| VPN/远控客户端 | 自报家门（记录真实端点） | 逐个盘点：不常用的用完即停+手动启动；常用的流量压进隧道使其记录的端点=出口 | `tailscale status` 等权限侧验证 |

## 浏览器层

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| 浏览器 DNS | DoH 设置 | 系统默认（交给转发器架构），防止双通道 | `chrome://settings/security` |
| WebRTC | STUN/主机候选 | `WebRtcIPHandling=disable_non_proxied_udp` 或由托管策略等效控制 | webrtc 检测站 |
| Accept-Language / navigator.language | 指纹主信号 | = 目标语言；界面语言经 `intl.locale_requested` 单独控制 | 检测站语言信号 |
| 历史语言痕迹 | profile 磁盘残留 | 迁移历史/清残留后，全 profile 无母语痕迹 | 磁盘检索 profile 目录 |
| 多身份串扰 | 同一 profile 混用国内外身份 | 每身份独立 profile，物理隔离 cookies/存储/指纹 | profile 清单 |

## 账号与元数据层

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| git 提交时间戳时区 | commit `+0800` 等 | 历史仓库：保留本人核心仓库的保真提交，其余删除；新提交用掩护时区或 UTC | `git log --format=%ai` |
| git 作者邮箱 | commit metadata | 公开仓库用专用中性邮箱 | `git log --format=%ae` |
| 账号注册资料 | 服务商侧 | 与掩护身份一致（昵称/头像/生日），不含真实信息 | 账号自检 |
| 支付元数据 | 卡 BIN/账单地址 | 可用虚拟卡/礼品卡降低关联；属半诚实残留 | 台账记录 |
| 客户端遥测开关 | AI 客户端 .settings.json 等 | 四项遥测开关全关（诊断/使用统计/反馈/个性化） | 配置文件核验 |

## 主动探测面

| 信号 | 泄露途径 | 目标状态 | 验证 |
|---|---|---|---|
| helper 进程偷 ping | 辅助进程访问国内常见站点探测可达性/时延 | 网络层已全压隧道：探测"成功"但只到达出口地；返回结果不含真实位置 | 进程网络日志 |
| 国内 DoH 偷跑 | 应用内置 DoH 到国内提供商 | DoH 端点域名整体进隧道（见 DNS 层） | 规则表 + 抓包 |
| 目标服务主动反查 | 对方服务回连检测 | 出口住宅 IP + 全套一致指纹通过对方校验 | cc.mastersgo.cc 类过关清单 |

## 服务端固有（诚实残留区）

对方服务端聚合类信号：KYC/KYB、支付关系、设备-账号关系图谱、行为速率、外部威胁情报、人工复核标签。网络与系统层全部闭合后这些自然收敛，但不可单方面消除。台账中标记为"接受残留"，以使用习惯管理（速率、时段）降低聚合价值。
