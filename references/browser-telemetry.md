## §1 浏览器指纹一致化

目标状态：界面显示用户母语，指纹报告掩护身份语言，两者稳定不矛盾。

1. **DNS**：浏览器 DoH 设为"使用系统 DNS"（或关闭）。浏览器的独立 DoH 会与系统转发器架构形成双通道，泄漏检测站会直接看到两条解析路径。此设置被组织策略锁定时（"您的浏览器由贵单位管理"横幅），优先解除策略锁；无法解除时确认当前策略值与架构兼容即可保留。
2. **WebRTC**：`WebRtcIPHandling` 策略值 `disable_non_proxied_udp`。语义：UDP 不经代理一律不发——STUN 只会暴露代理出口，真实 IP 无路径可走。注意它只影响不经代理的 UDP；TUN 全局接管时真实 IP 本就无直连通道，该策略是双保险。
3. **语言解耦**（Chrome 系）：
   - `intl.locale_requested` = 目标语言（进入 Accept-Language / navigator.language 指纹）
   - 界面显示语言保持母语
   - 历史 profile 迁移或清残留：全 profile 目录磁盘检索母语痕迹，清干净再上线
4. **多身份隔离**：每个身份独立 profile（独立 cookies/存储/扩展/指纹），跨身份不共享窗口。无痕模式只是本 profile 内隔离，不等于多身份。
5. **策略锁解除**：HKLM/HKCU 下浏览器策略残留会导致设置灰化。查清每个策略键的来源与当前值；值与目标一致可保留，冲突则删键后重启浏览器验证。

## §2 遥测阻断（温和清单）

原则：只拦"纯遥测域名"（拦了不影响应用功能），应用主域名一律不碰；引流优先于拦截。

| 类别 | 域名 |
|---|---|
| 通用崩溃/性能遥测 | `sentry.io`、`datadoghq.com`、`datadoghq.eu` |
| AI 客户端统计 | `oaistatsig.com`、`*.exp-tas.com`（实验框架） |
| Copilot 采集端点 | `telemetry.individual.githubcopilot.com`、`copilot-telemetry.githubusercontent.com`、`collector.github.com`、`collector.githubapp.com` |
| 编辑器遥测 | 编辑器自身的 api2 遥测子域（按实际抓包补充） |

落地位置：代理客户端 REJECT 规则（置于白名单之后、兜底之前）。注意：遥测与功能同域时不可拦——宁可放行不可误伤（用户点名的原则）。客户端本地遥测开关（诊断/使用统计/反馈/个性化四类）先于域名层关闭，能关尽关。

## §3 helper 探测面防护

应用主程序不联网，辅助进程（helper/updater/crashpad）偷偷探测的场景，按优先级处置：

1. **网络层收口（已覆盖 90%）**：TUN + 兜底 MATCH 下，helper 的任何连接都到达出口地。探测国内站点"成功"但看到的全是掩护面。
2. **DoH 通道封死**：见 proxy-dns-architecture.md §2 DoH 硬化。helper 硬编码 DoH 到国内提供商时，端点域名在隧道内，应答来自出口地或超时回落。
3. **进程级白名单（精准处置）**：对具体高危 helper 进程单独配规则（观察其实际连接后决定直连/代理/拒绝）。维护成本最高，仅对确认高危者使用。
4. **内网/回环探测**：应用 ping 局域网地址探测"是否在内网"——阻断出站不可行时（温和原则），依赖网络层让探测结果只反映出口侧。

验证法：抓包/连接日志看 helper 进程的实际目标，逐进程建档。

## §4 国产自保护软件处置原则

此类软件（带自我保护驱动/服务的安全组件、DRM、反作弊）通常：本地采集面大（软件列表/进程/位置）、自我保护强（服务无法停止、文件拒绝访问）、同时是某些应用的运行依赖。

既定策略"允许采集、采集面缺失"：
- **不卸载**——保持依赖它的应用可用，也保留作为本地采集行为的观察样本。
- **网络层收口**——它的外发流量全部经过隧道，对方只看到掩护面。本地采集结果不再指向真实位置。
- **尸体清理**——其历史版本残留目录受文件 ACL 保护删不动时：`takeown /f <dir> /r /d y` + `icacls /grant administrators:F /t` 夺权后强删。服务自保护只锁运行态，静态副本夺权即可清除（实测 400+ 文件可删，服务全程运行不受影响）。
- **权限纪律**——日常终端不提权；不可信程序绝不在管理员环境运行（它读本机状态需要权限，降权=缩面）。
