# 系统信号层：系统与硬件指纹的收敛

网络层全部闭合后，应用与网站仍能从操作系统直接读取一批"无门槛信号"。这一层的原则：**能改值的改值，改不了的收紧权限，两者都做不到的记入缺口清单**。

## 时间与区域

| 信号 | 处置 | 验证 |
|---|---|---|
| 时区 | 设为掩护身份时区。对国内用户，UTC+9（东京）与真实作息天然兼容，无需倒时差伪装 | `tzutil /g`、检测站时区项 |
| 系统区域格式 | 控制面板"区域"→格式选掩护国（如日语/日本）。区域决定 API 返回的货币/日期/排序指纹 | 检测站 locale 项 |
| 显示语言 | 可与区域解耦：界面继续用母语，指纹报掩护国（浏览器层用 `intl.locale_requested` 单独控制） | 目视 + 指纹站对照 |

## 标识符

| 信号 | 处置 | 验证 |
|---|---|---|
| MachineGuid | `scripts/rotate-machine-guid.ps1` 备份后轮换为随机 GUID（需提权一次）。MachineGuid 是软件最常用的设备指纹根值， worth 轮换 | 脚本回读新值；台账记录旧值用于回潮检测 |
| 计算机名/用户名 | 中性化（如 `DESKTOP-<random>`/无真实姓名）；改动影响共享/证书路径需先评估 | 台账记录决策 |
| MAC 地址 | 通常不跨境泄露（不经过出口），一般保留 | — |
| SMBIOS/序列号 | 需本地权限读取 → 收紧日常权限：日常终端不默认提权，不可信程序绝不在管理员环境运行 | 权限实践检查 |

## 服务与组件盘点

1. **遥测服务禁用**：`DiagTrack`（客户体验改善）、`dmwappushservice`（WAP 推送）设为禁用并停跑。这是系统级遥测的主通道。
2. **开机自启全量盘点**：启动文件夹/Run 键/计划任务三项全列，逐项标注保留理由；无头无脸的一律清。审查重点是"谁在开机时向外说话"，而不是启动快慢。
3. **国产"安全/管家"类软件**：按"允许采集、采集面缺失"原则处置——不卸载（保持系统组件与应用可用，它本身也是一块验证防护有效性的试金石），但其能采到的内容不指向真实位置：网络层全压隧道后，它外发的一切自然只含掩护面。两条纪律：不给它不必要的提权运行场景；它的残留目录/历史版本尸体在卸载其他组件时一并清理。
4. **输入法**：关闭云同步/用户体验计划；常驻弹窗报错的输入法组件（云候选进程）直接禁用其联网或自启。输入法词库是高度身份化的信号。
5. **VPN/远控/ mesh 客户端**（Tailscale/ZeroTier/向日葵/ToDesk 一类）：自报家门型泄漏源——客户端设计上必须知道你的真实公网端点并记录在本地。逐个盘点二选一：**不常用** → 用完即停 + 服务改手动启动（停止状态下无任何端点记录可读）；**常用** → 其全部流量压进隧道，使其记录的端点=出口地。权限侧验证：用非管理员账户跑客户端状态命令，权限错误=普通应用读不到，泄漏面仅管理员进程。
6. **第三方"清理/优化"工具**（历史教训：CCleaner 类）：清理工具拥有最高文件可见性，是采集面而非防护面。保留需逐条理由，默认倾向移除。

## 权限纪律（贯穿全层）

应用的管理员权限改变不了网络层的判决：TUN、防火墙、DNS 劫持都工作在内核层，应用无法选择"绕过网卡"。真正需要提防的是恶意驱动/rootkit 级组件——那是"不装来路不明的软件"这条安装纪律的范畴，任何配置层方案都无法事后补救。日常习惯：终端不默认提权；安装包弹 UAC 时先想"这个软件为什么需要"。
