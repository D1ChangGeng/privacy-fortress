# 深矩阵威胁模型：对 AI 服务商可见的每一类信号与处置

本文件把 AI 服务商（以 Anthropic 政策文本为样本）理论上可观察的**全部**信号面逐层列出，不因其"暂无证据被采集"而省略。证据分级：**A**=政策明确披露 / **B**=其他官方文档确认 / **T**=技术可行但无公开证据 / **N**=对方明确称不采集。处置列是本 skill 覆盖的判定：✅已闭合 / 🔧已修复 / ⚠️纪律项 / 📌账号侧 / 🧾诚实残留。

## 一、身份/支付/KYC 层（A）

| 信号 | 级别 | 处置 |
|---|---|---|
| 姓名/邮箱/手机号/组织 | A | 📌账号侧：与掩护身份一致，不与真实身份服务共用邮箱 |
| 账号 ID/会话/登录历史 | A/T | 📌登录时机：画像就绪后再登录，绑定前是调整窗口 |
| 账单地址/邮编/国别/BIN/发卡国 | T | 📌支付国别必须与出口国一致，否则触发 IP↔billing 一致性特征 |
| KYC 证件/人脸 | A | 🧾架构固有上限：触发即不可伪造，以降低触发率为目标 |
| Stripe/CF 安全 cookie | B | 🧾第一方固有，清 cookie≠换身份（账户轴仍在） |

## 二、IP/网络/传输层（A/B/T）

| 信号 | 级别 | 处置 |
|---|---|---|
| 公网 IPv4/历史 IP/GeoIP 国家 | A/B | ✅住宅出口 + 全量在隧道内 |
| 公网 IPv6 | A/T | ✅无 v6 出境（curl -6 失败 + iplark "获取失败"）；WLAN 未绑 v6 |
| ISP/ASN/住宅分类/信誉分 | A/T | ✅选购住宅 IP 时已验 ASN 与欺诈分；每日巡检复测 |
| mobile operator/MCC/MNC | A | ⚠️纪律：访问目标服务期间禁手机热点（运营商=最强国家信号之一） |
| TLS/JA3/TCP/HTTP2 指纹 | T | 🧾真实浏览器/客户端栈不可伪造也不需要伪造：指纹↔UA 一致即低风险；混杂代理链不改终端指纹 |
| RTT/多区域时延三角定位 | T | 🧾部分缓解：链式路由固定，时延画像=出口国；接受残留 |
| DNS resolver 身份/DNS leak | T | ✅fake-ip+dns-hijack+本地转发器；DoH 硬化进隧道；深度泄露测试每日必测 |
| WebRTC 公网/私网地址 | T | ✅WebRtcIPHandling=disable_non_proxied_udp + 定位全局阻止 |
| X-Forwarded-For | T | ✅TUN 出口不产生 XFF（无浏览器内嵌代理） |

## 三、直接/间接位置（A/T/N）

| 信号 | 级别 | 处置 |
|---|---|---|
| IP-derived location | A/B | ✅=出口国 |
| 系统时区/UTC偏移/DST | A/T | ✅=出口国时区 |
| 系统区域/区域格式/货币 | T | ✅GeoId+Culture 与出口国一致（如 ja-JP 格式）——IP↔timezone↔locale↔currency 四条一致性轴全部对齐 |
| Preferred languages | T | ✅浏览器 Accept-Language 无真实语言 |
| 键盘布局/输入法 | T | 🧾中文输入法在用=诚实残留（网络面无法采集，仅行为统计弱信号） |
| GPS/WiFi/BT/基站定位 | N | ✅对方明确不采集；且 Geolocation 权限全局阻止双保险 |
| WiFi SSID/BSSID（本机读取面） | N/T | 🧾本地可读无法系统级阻止，核心靠外发全走白名单审计 |
| 图片 EXIF GPS | T | ⚠️纪律：上传图片前剥离 EXIF（手机原图必带 GPS） |

## 四、浏览器/Web 指纹（A/T）

| 信号 | 级别 | 处置 |
|---|---|---|
| UA/Client Hints/UA↔OS 一致性 | A/T | ✅真实 Chrome，无需伪造 |
| Canvas/WebGL/Audio/字体指纹 | T | 🧾接受残留（概率标识轴）：不追求唯一性清零，追求"不指向真实位置" |
| 屏幕/CPU/内存/GPU | T | 🧾同上；虚拟机方案被否决后此为既定取舍 |
| navigator.languages/时区 | T | ✅已对齐 |
| localStorage/IndexedDB/Storage 轴 | T | 🧾第一方存储固有；清 profile 只减熵不减轴 |
| 剪贴板 | T | ⚠️纪律：复制敏感内容后勿立即粘贴进 AI 对话 |

## 五、Cookie/持久标识（B）

sessionKey/__ssid/Stripe/CF/Intercom/分析 ID 全部第一方固有。📌教训：**清 cookie/换 IP≠新设备**，账户轴、支付轴、安全 cookie 轴独立存在。不要在多个账号间复用同一浏览器 profile 做对照操作。

## 六、Desktop/OS 原生面（A/T）

| 信号 | 级别 | 处置 |
|---|---|---|
| MachineGuid/OS machine ID | T | 🔧定期轮换+写入必二次校验（轮换假成功案例） |
| Hostname/用户名/家目录 | T | 🧾中性化评估；CLI 场景注意路径入上下文（见下节） |
| MAC 地址 | T | ✅随机化（本地管理位） |
| 网卡列表/VPN 接口存在 | T | 🧾揭示用代理=低价值信号，接受 |
| 已装软件/运行进程/环境变量 | T | ⚠️AI Agent(CLI) 类应用可经工具读取并送入上下文——见第八节纪律 |

## 七、行为/时序（A/T）

⚠️全部纪律项：速率贴出口国作息；避免批量自动化与并发远距会话（impossible travel 特征）；避免短时限多账号切换。自动化节奏是强风控特征——人味本身就是防护。

## 八、CLI/Agent 环境面（Claude Code 类，B/T）——独立章节

CLI Agent 比 Web 多出的不是指纹，而是**本地执行面**。以下信号会经工具结果进入模型上下文并可能留存：

| 信号 | 处置 |
|---|---|
| 工作目录/仓库名/分支/git remote | ⚠️避免在含真实身份线索的目录结构下使用；git remote 用中性命名 |
| git author/email/提交时区 | ✅历史已改写（noreply+出口国偏移）；新仓库默认中性身份 |
| 终端输出中的路径（C:\Users\<真实用户名>） | ⚠️粘贴/引用工具输出前自我审查；可考虑建立中性目录软链作为工作区 |
| 环境变量（USERNAME/COMPUTERNAME） | 🧾Agent 读取即入上下文；降低方式=中性用户名（高成本，可选） |
| 凭据/.env/日志文件 | ⚠️绝不把含密钥、内网 IP、真实地址的文件直接喂给 Agent；上传前审查 |
| /bug 类全量上报指令 | ⚠️官方确认会发送完整对话含代码——敏感会话勿用 |
| Statsig/Sentry 遥测 | B 确认存在；域名层处置：纯遥测 REJECT，功能依赖时改链式（引流优先） |
| MCP/Connector 授权 | 📌按需最小授权；邮件/日历类连接器含地址/日程=高地理价值 |

## 九、文件/图片 metadata（A/T）

Office/PDF 作者元数据、源码注释中的内网 IP/主机名、日志中的公网 IP、截图中的地址——**这类面常比浏览器指纹更容易意外泄露**。处置：上传/粘贴前审查；批量剥离工具（exiftool）纳入新文件入库流程。

## 十、一致性派生特征（C级，风控真正的算分对象）

IP↔account country / IP↔billing / IP↔timezone / IP↔locale / IP↔carrier / 历史IP / impossible travel / 设备连续性 / 支付连续性 / 多账号同设备——**每条轴的处置都已在前九节落实**。收尾自检问一句：任意两条轴交叉，是否都指向同一掩护身份？这是比单点检查更高的通过标准。

## 处置优先级速查

1. 未闭合的 A/B 级 > 一切 T 级。
2. 一致性轴（第二节+第十节）> 单点指纹。
3. 账号侧三项（邮箱/支付/登录时机）由使用者最终确认——Agent 无法代办。
4. N 级（GPS/WiFi/BT）不投入任何工程资源。
